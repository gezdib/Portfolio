Subcontract Log Updater

Upload the current contracts file (the MDOT tracking log) and the newest Subcontract Log PDF. The tool lines the two up by contract number, shows you every difference it finds, and only writes the changes you approve into an updated copy of your file. Nothing is uploaded anywhere: everything runs on this page, in your browser.

1Upload the two files

The contracts file is the state you want to update. The PDF log is the newest data that wins. Amounts are compared to the cent. A row whose contract number appears in the PDF but not in your file is proposed as a new row. Nothing is ever deleted.

Contracts file (current state)
Excel or CSV, for example the MDOT Tracking Log (.xlsx, .xls, .csv)
Subcontract Log PDF (newest data)
The printed Subcontract Log as a text-based PDF (Print to PDF works). Scanned images will not read.
Sample data is fictional and shows one amount update, two filled-in blanks, and one new subcontractor.

2Check what was read from the PDF

These are the rows extracted from the PDF log. The totals check compares the sum of the extracted rows against the totals printed on the log itself: if a row had been missed or misread, the sums would not match. You can correct any cell here before comparing, and anything you change is what gets compared.

3Confirm which columns get updated

The PDF log and your file name their columns differently, so confirm the matches below. Only these four amounts are ever written. The PDF's Pending, Invoiced and Retained amounts have no matching column in the tracking log and are never written.

4Review the changes

Every difference found is listed below. Untick anything you do not want applied. The updated file is only produced when you press the button, and your original file is never modified.

5Download the updated file

Subcontract Log Updater. Files are processed locally in your browser and are never sent to a server.
Always spot-check the change report against the PDF before using the updated file.
